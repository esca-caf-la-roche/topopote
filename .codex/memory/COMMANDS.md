# Commands

## Development

```powershell
npm.cmd install
npm.cmd run dev
```

## Verification

```powershell
npm.cmd run lint
npm.cmd run test
npm.cmd run build
```

## Supabase

```powershell
supabase link --project-ref VOTRE_REFERENCE
supabase db push
```

## Repository inspection

```powershell
git status --short
git log --oneline -10
```
