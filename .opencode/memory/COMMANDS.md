# Commandes

- `npm.cmd run lint`
- `npm.cmd run test`
- `npm.cmd run build`
- `npm.cmd run test:db` (nécessite Supabase local)
- `supabase db push --linked --dry-run --skip-vault` : contrôle distant documenté, pas exécuté automatiquement.
- Voir `README.md` pour la livraison et les prérequis Node.js 22 / Supabase CLI.
